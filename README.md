## 关于

我关注 AI 与攻击性安全的交叉点：自主渗透 Agent、Agent 运行时安全、代码审计（Java / Go / PHP）。

技术上我在意的是"能不能被信任"，不是"能不能跑通"。这两个词的差别，是我大部分文章的主题——也是我大部分返工的原因。

## 在做什么

**horizon** — 单主 Agent 安全探索运行时。可追溯输入、可回读证据、可修订判断；用真实任务结果和成本检验价值，不用 benchmark 分数自我证明。

**loom** — 织序。供工具与 Agent 消费的语义数据基座，把材料、命题、证据组织成可被检索与推理的结构，而不是再叠一层工作台。

两个都在私有仓库。代码不在这里，判断在这里。
